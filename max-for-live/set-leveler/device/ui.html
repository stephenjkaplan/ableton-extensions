Set Leveler (DJ Set)

Uses Arrangement as a guide to what plays at the same time, and changes gain on Session clips.

Good to know
  • A hand-trimmed layer stays trimmed: it moves with its track. A hand-trimmed track goes back to the target on the next Apply, unless it's set to Leave alone.
  • Measures clip audio: each clip's file plus its clip gain. Track devices, clip envelopes and the master don't count.
  • Only Session gain changes. Arrangement, devices and audio files stay as they are, and it never saves your Set.
  • Layers: a clip that sits mostly inside one longer clip in Arrangement, on any track. Check them with See every clip.
  • Undo only touches clips still in the same slot. If you insert a scene or track, put the clips back to finish it.
  • Transitions still add up: two tracks at full level run about 3 dB louder than one.
