# Ableton Extensions SDK — vendored reference

The SDK is **not published to npm**. It ships with the Live 12 beta program download
(`extensions-sdk-1.0.0-beta.1`). The tarballs are vendored at
`extensions/stem-export/vendor/` and referenced from `package.json` as `file:` deps.

- `sdk-api.d.ts` — the SDK's shipped type definitions, copied verbatim for reference.
- `SDK-LICENSE.md` — Ableton's SDK licence. Read before redistributing anything here.

Upstream docs (HTML) and examples live in the original download, not committed.
